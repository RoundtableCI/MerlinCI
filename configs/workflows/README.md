# Workflow templates

Workflow templates are an extension point (slide 16, `pkg/workflowtemplate`).

The first release ships one workflow, end to end (slide 14):

1. Researcher finds a public opportunity
2. Evidence and sources are saved
3. Strategist writes a campaign brief
4. Content role creates an asset
5. Brand Guardian checks accuracy and quality
6. Distribution prepares or publishes
7. Analytics records the campaign and results
8. Run is inspectable, costed and recoverable

The full signal-to-next-cycle flow (slide 9) follows as roles ship.
