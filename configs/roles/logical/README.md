# Logical roles

The plan defines 18 logical roles that run on 8 runtime roles (slide 8). A logical role is
split out only when its tools, workload or evaluation justify it.

Release order (slide 13):

| # | Role | Outcome |
|---|---|---|
| 00 | Foundation | One agent takes a task, uses a tool, stores a validated artifact and recovers |
| 01 | Market Researcher | Evidence-backed market intelligence feed |
| 02 | Competitor Analyst | Ongoing competitive intelligence |
| 03 | Strategist | Research becomes campaign briefs |
| 04 | Content and Social | A repeatable content pipeline |
| 05 | Brand Guardian | Quality control before distribution |
| 06 | SEO Specialist | An organic search workflow |
| 07 | Distribution | Approved assets go out without hand-operating each channel |
| 08 | Creative and Demo | Real product demonstrations and visual campaigns |
| 09 | Analytics | Know which activity produces meaningful users |
| 10 | CMO orchestration | Coordinated autonomous marketing |
| 11 | Leads and Growth Lab | Only when data, permissions and compliance are ready |

Do not enable a role merely because its prompt has been written.
