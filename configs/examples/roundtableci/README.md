# RoundtableCI — reference deployment

RoundtableCI is customer one, not a dependency (slide 7). MerlinCI markets RoundtableCI first;
other companies run their own by supplying their own version of these files.

Planned files:

| File | Contents | Deck |
|---|---|---|
| `profile.yaml` | Approved product profile: brand, products, objectives, channels | slide 7 |
| `audiences.yaml` | Audience hypotheses (to validate, not facts) | slide 7 |
| `policy.yaml` | Autonomy tiers per action and channel | slide 11 |
| `budget.yaml` | ₹150/day inference cap, ₹3,000/month inference, ₹500/month research APIs; alerts at 70% and 90% | slide 15 |

Audience hypotheses from the deck:

- Developers using multiple models
- Developers comparing model outputs
- AI product builders, technical founders
- Engineering leads weighing AI workflows
- Researchers testing model evaluation

Claims rule: no claim that RoundtableCI is more accurate, faster, cheaper or superior without a
specific, reproducible evaluation. Say no more than the record supports.
